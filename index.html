Why this exists

Most manufacturers plan production around a guess dressed up as a forecast — a spreadsheet trend line, a gut feeling, or "what we made last time." When that guess is wrong, it shows up as late deliveries, raw materials ordered too late or in the wrong amounts, and production chasing demand instead of anticipating it. PDAT was built to close that gap: give planners an actual, tested forecast to work from, before the backlog builds up rather than after.

02

What it actually does

You feed it historical demand numbers — a spreadsheet, a shared online file, or typed in by hand. It runs three different forecasting approaches side by side, scores each one against five accuracy measures, and tells you which model to trust and what number to plan for next period.

03

Three models, one answer

A straight-line trend model, an exponential smoothing model, and (when available) Meta's Prophet model each produce their own forecast. PDAT ranks them, shows you the numbers behind the ranking, and highlights the one it recommends — no need to know which model is "right" beforehand.

04

Built for everyday use

Runs in light or dark mode, in three languages (English, isiZulu, and Afrikaans), and exports straight to a live, editable Excel workbook with its own chart — so the recommendation drops directly into whatever planning process the team already uses.

Help & Instructions

Getting PDAT running, and using it well

Everything from checking your computer is ready, to changing the language on the fly.

ASetting Up The Device

Checking if Python is installed

  1. Open Run (press Windows + R).
  2. Type cmd and press Enter.
  3. In the black window, type python --version and press Enter.

You should see something like Python 3.11.5. If instead you see 'python' is not recognized..., Python isn't installed properly yet — see the next step.

Installing Python (if it's missing)

  1. Go to python.org/downloads and download the latest version for your operating system.
  2. Run the installer — tick "Add Python to PATH" before clicking Install. This one checkbox is what the previous step depends on.
  3. Once it finishes, close and reopen Command Prompt, then re-run python --version to confirm.

Installing the required packages

PDAT relies on a handful of Python libraries. With Command Prompt open, run:

pip install pandas numpy scikit-learn matplotlib requests openpyxl pillow

Prophet (the third forecasting model) is optional — PDAT still runs fine without it, just with two models instead of three:

pip install prophet

Running PDAT

  1. If you were given an installer (PDAT_Setup.exe), just double-click it and follow the install wizard — no Python setup needed on that machine.
  2. If you're running from source, open Command Prompt in the folder containing the app and run python PDAT.py.
  3. The first time you open PDAT, you'll be asked for a username and access code (sent to you when your account was registered). Keep these confidential — losing them means a new access code has to be generated, which may come at an additional cost.
  4. Your account works on up to 3 devices at a time.

BInstructions

Loading your data

PDAT accepts a single column of numeric demand values, with at least 15 entries. Three ways in:

  • Upload from Local — pick an Excel (.xlsx/.xls) or CSV file from your computer.
  • Upload from Online — paste a direct file URL, or a OneDrive/SharePoint sharing link.
  • Insert Data Manually — type values in one at a time, in a scrollable grid (5 to 1000 rows).

Running the analysis

Once data loads, click Run Predictive Analysis. PDAT fits all available models and ranks them automatically — this takes a few seconds.

Reading your results

  • Results table — each model's average error, color-coded green (best), skyblue (second), red (third).
  • Detailed Errors — the full breakdown across all five accuracy metrics.
  • Graph — actual demand vs. every model's fitted line, on one chart.
  • Next Period Forecast — the single number to plan around, from the best-ranked model.

Exporting to Excel

Click Export to Excel to get a workbook with your raw data, the ranked results (color-matched to the app), a detailed errors sheet, and a Graph sheet with a live, editable native Excel chart.

Changing the language

Click the ⚙ Settings icon (top-right, on every screen), then pick a language from the dropdown — English, isiZulu, or Afrikaans. The whole interface updates immediately, no restart needed.

Changing the background (theme)

In the same Settings screen, choose Dark or Light using the radio buttons. It applies instantly and is remembered the next time you open PDAT.

Resetting to defaults

Settings → Reset. You'll be asked to confirm, since this reverts both theme and language back to Dark + English.

CTroubleshooting

"'python' is not recognized..."

Python wasn't added to your system PATH during install. Reinstall and tick "Add Python to PATH", or try py --version instead as a quick check.

"Invalid File" when uploading

Your file needs exactly one column of numbers, with at least 15 valid rows after removing blanks or text entries. Extra columns or headers in the wrong place will trigger this.

Only two models show up in results

Prophet is optional — if it isn't installed, PDAT still runs Linear Regression and Smoothing normally, and shows Prophet as unavailable rather than failing.

OneDrive link won't load

Make sure it's a "Anyone with the link can view" sharing link, not one requiring sign-in or a password.

Settings don't seem to save

PDAT needs permission to write a small settings file next to itself — if it's running from a protected folder (like Program Files), move it somewhere with normal write access, such as your Documents folder.

Excel export fails

Usually means the target file is already open in Excel — close it and try exporting again. If it still fails, confirm openpyxl is installed (see Setting Up The Device above).

620def mae(y_true, y_pred):
621 return float(np.mean(np.abs(y_true - y_pred)))
622
623
624def rmse(y_true, y_pred):
625 return float(np.sqrt(np.mean((y_true - y_pred) ** 2)))
626
627
628def mape(y_true, y_pred):
629 vals = [abs((yt - yp) / yt) for yt, yp in zip(y_true, y_pred) if yt != 0]
630 return float(np.mean(vals) * 100) if vals else 0.0
631
632
633def smape(y_true, y_pred):
634 vals = []
635 for yt, yp in zip(y_true, y_pred):
636 denom = (abs(yt) + abs(yp)) / 2
637 if denom != 0:
638 vals.append(abs(yt - yp) / denom)
639 return float(np.mean(vals) * 100) if vals else 0.0
640
641
642def wape(y_true, y_pred):
643 denom = np.sum(np.abs(y_true))
644 if denom == 0:
645 return 0.0
646 return float((np.sum(np.abs(y_true - y_pred)) / denom) * 100)
647

649def average_error(mae_v, rmse_v, mape_v, smape_v, wape_v):
650 return float(np.mean([mae_v, rmse_v, mape_v, smape_v, wape_v]))

656def linear_regression_forecast(series):
657 y = series.astype(float).values
658 x = np.arange(len(y)).reshape(-1, 1)
659 model = LinearRegression()
660 model.fit(x, y)
661 fitted = model.predict(x)
662 next_val = float(model.predict(np.array([[len(y)]]))[0])
663 return fitted, next_val

666def smoothing_forecast(series, alpha=0.3):
667 y = series.astype(float).values
668 fitted = np.zeros(len(y))
669 fitted[0] = y[0]
670 level = y[0]
671 for t in range(1, len(y)):
672 fitted[t] = level
673 level = alpha * y[t] + (1 - alpha) * level
674 next_val = float(level)
675 return fitted, next_val

678def prophet_forecast(series):
679 if not PROPHET_AVAILABLE:
680 raise ImportError("Prophet is not installed. Install it with: pip install prophet")
681 y = series.astype(float).values
682 dates = pd.date_range(start="2024-01-01", periods=len(y), freq="D")
683 df = pd.DataFrame({"ds": dates, "y": y})
684 model = Prophet(daily_seasonality=False, weekly_seasonality=True, yearly_seasonality=False)
685 model.fit(df)
686 future = model.make_future_dataframe(periods=1, freq="D")
687 forecast = model.predict(future)
688 fitted = forecast["yhat"].iloc[:len(y)].values
689 next_val = float(forecast["yhat"].iloc[-1])
690 return fitted, next_val

1201 def run_analysis(self):
1202 series = self.data["Actual Demand"]
1203 y_true = series.astype(float).values
1204
1205 results = []
1206 predictions = {}
1207
1208 lr_fitted, lr_next = linear_regression_forecast(series)
1209 predictions["Linear Regression"] = lr_fitted
1210 results.append(self._evaluate("Linear Regression", y_true, lr_fitted, lr_next))
1211
1212 sm_fitted, sm_next = smoothing_forecast(series)
1213 predictions["Smoothing"] = sm_fitted
1214 results.append(self._evaluate("Smoothing", y_true, sm_fitted, sm_next))
1215
1216 if PROPHET_AVAILABLE:
1217 try:
1218 pp_fitted, pp_next = prophet_forecast(series)
1219 predictions["Prophet"] = pp_fitted
1220 results.append(self._evaluate("Prophet", y_true, pp_fitted, pp_next))
1221 except Exception:
1222 results.append(self._failed_model("Prophet"))
1223 else:
1224 results.append(self._failed_model("Prophet (not installed)"))
1225
1226 results.sort(key=lambda r: r["average_error"])
1227 colors = ["green", "skyblue", "red"]
1228 for idx, r in enumerate(results):
1229 r["rank"] = idx + 1
1230 r["color"] = colors[idx] if idx < len(colors) else "gray"
1231
1232 self.model_results = results
1233 self.graph_payload = {
1234 "periods": list(range(1, len(series) + 1)),
1235 "actual": y_true.tolist(),
1236 "predictions": {k: v.tolist() if hasattr(v, "tolist") else v for k, v in predictions.items()},
1237 }
1238
1239 self.show_results()

1242 mae_v = mae(y_true, y_pred)

1244 mape_v = mape(y_true, y_pred)

1246 wape_v = wape(y_true, y_pred)
1247 avg = average_error(mae_v, rmse_v, mape_v, smape_v, wape_v)
1248 return {
1249 "model_name": name,
1250 "mae": round(mae_v, 4),
1251 "rmse": round(rmse_v, 4),
1252 "mape": round(mape_v, 4),
1253 "smape": round(smape_v, 4),
1254 "wape": round(wape_v, 4),
1255 "average_error": round(avg, 4),
1256 "next_period_forecast": round(next_val, 4),
1257 }
